## Uso de la herramienta
Descarga `herramienta_caso5_puntada.html` y ábrelo en un navegador moderno. No requiere instalación ni conexión a internet.

## Datos y alcance
Los datos del caso se mantienen como base. Los resultados de capacidad se calculan con un modelo determinista de flujo P → S → F, una máquina compartida y asignaciones fijas por etapa. Las conclusiones y limitaciones están documentadas en el informe.
